# Art Flores – site em Next.js

    npm install
    npm run dev      # http://localhost:3000

Edite `lib/data.js`: telefone do WhatsApp (55 + DDD + número), endereço, horários, taxas e produtos.
Para usar fotos, coloque em `/public` e adicione `img: "/nome.jpg"` no produto.
Deploy: Vercel (`vercel`) ou `npm run build && npm start`.
